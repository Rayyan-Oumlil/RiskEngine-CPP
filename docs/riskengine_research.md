## 0. Thesis and risk taxonomy

Analytic Black-Scholes, the CRR tree and Monte Carlo under GBM are **one model and three numerical methods**. Their convergence to the same price is a *correctness gate*, not a finding. The project studies three distinct objects, and the report never conflates them:

| Object | Question | Where it is shown |
|---|---|---|
| **Numerical-method risk** | How fast and how reliably does each method converge? Where do naive implementations break silently? | §3, §4, §5 |
| **Risk-measure risk** | Why do two reasonable measures (delta-normal VaR, full-revaluation VaR) give radically different answers on the same position? | §6 |
| **Model risk** | What happens when the *assumptions* change (stochastic volatility, jumps) while the price of ATM vanillas stays the same? | §7 |

**Guiding principle:** the risk of a number is a property of the number, not of the code. A Monte Carlo price without a standard error, a Greek without a bias/variance analysis, a VaR without a confidence interval or a backtest are not results. The architecture must make these omissions hard, ideally impossible at compile time.

## 1. What changes from v1

v1 is solid on the mathematics (all its reference values were reconfirmed). v2 fixes or tightens the following points:

| # | v1 | v2 | Why |
|---|---|---|---|
| 1 | `std::mt19937_64` per thread + `std::normal_distribution` | **Philox 4×32-10** (counter-based RNG) + **in-house inverse normal** (Wichura AS241) | `std::normal_distribution` and `std::uniform_real_distribution` are *implementation-defined*: same seed, different results under libstdc++, libc++ and MSVC. Incompatible with a 3-compiler CI and a report full of numbers. |
| 2 | `PriceResult` / `double` | Mandatory **`Estimate`** type (value, standard error, discretization bias, n) | Makes it impossible for an MC price to travel without an error bar; separates statistical error from scheme bias (critical for Heston). |
| 3 | MC pricer with an internal seed | **Stochastic pricer = pure function of (market, seed)** | Common random numbers become trivial and non-optional. |
| 4 | `std::mdspan`, `std::expected`, `consteval norm_cdf` listed as C++20 | Removed or replaced | `mdspan` and `expected` are C++23; `std::erfc` is not `constexpr` in C++20. Decision: **we stay strictly C++20** (in-house 2-D view, in-house `Result` type instead of `std::expected`). No switch to C++23 — that would be scope creep for a marginal gain. |
| 5 | `-ffast-math` recommended for vectorization | **Forbidden** in reference builds; allowed only in an isolated `bench-fast` preset | Breaks NaN tests, compensated summation and bit-for-bit reproducibility. |
| 6 | MC test at 3×SE | **4×SE** with a fixed seed | 3σ fails 0.27 % of the time per test; with dozens of statistical tests, false positives become routine. |
| 7 | MC Greeks: FD+CRN, pathwise, LR on a call | **Payoff × estimator matrix** including a **digital** | The strongest result is the *silent* failure of pathwise on a digital (derivative zero a.s.) and the failure of CRN on discontinuous payoffs. |
| 8 | Heston as a "stretch" | **A full phase** (§7), but **explicitly the first thing to cut** if time runs short (§12.1) | Without alternative assumptions, the word "model" in *model risk* is not earned — but a part-time student project must not sacrifice §1–§6 (the core, already differentiating) for Heston. |
| 9 | Historical stress = thesis phase | Historical stress **merged with historical VaR and backtesting** (§6, §9) | Same data infrastructure; avoids a redundant phase. |
| 10 | No experiment harness | **Dedicated infrastructure phase**: each figure = one executable + CSV + metadata | The report must be regenerable with one command. |
| 11 | Variance techniques compared by standard error | Compared by **efficiency = 1 / (variance × CPU time)** | A variance reduction that costs more than it saves is a regression. |

## 2. C++20 architecture

### 2.1 The real problem: a partially valid Cartesian product

The engine handles **Model × Payoff × Method**. Not every combination exists: no recombining tree for Heston, no closed form for a barrier under Heston, no useful pathwise estimator for a digital. The architecture encodes this validity instead of discovering it at run time.

### 2.3 Fundamental types

```cpp
// Strong typedefs: kill the sigma vs sigma^2 and percent vs decimal classes of bugs.
struct Spot     { double v; };
struct Strike   { double v; };
struct Vol      { double v; };   // decimal, per year
struct Rate     { double v; };   // decimal, continuous compounding
struct Maturity { double v; };   // years (convention documented in conventions.md)

struct MarketState {
    Spot spot; Rate rate; Rate div; Vol vol;
};

// Universal return type. No price travels as a bare double.
struct Estimate {
    double value;
    double std_error      = 0.0;  // statistical error (0 if deterministic)
    double discretization = 0.0;  // known or estimated scheme bias
    std::size_t samples   = 0;
};
```

### 2.4 Concepts

```cpp
template <class P>
concept Pricer = requires(const P& p, const MarketState& m) {
    { p.price(m) } -> std::same_as<Estimate>;
};

// A stochastic pricer is a pure function of (market, seed key).
// No internal mutable RNG state: CRN are obtained by calling again with the same key.
template <class P>
concept StochasticPricer = requires(const P& p, const MarketState& m, SeedKey k) {
    { p.price(m, k) } -> std::same_as<Estimate>;
};

// Stochastic dynamics, decoupled from the solvers.
template <class M>
concept PathModel = requires(const M& m, typename M::State s, double dt,
                             std::span<const double> z) {
    { M::factors }         -> std::convertible_to<std::size_t>;
    { m.initial_state() }  -> std::same_as<typename M::State>;
    { m.step(s, dt, z) }   -> std::same_as<typename M::State>;
};

template <class F> concept TerminalPayoff = requires(const F& f, double s) {
    { f(s) } -> std::convertible_to<double>;
};
template <class F> concept PathPayoff = requires(const F& f, std::span<const double> path) {
    { f(path) } -> std::convertible_to<double>;
};

// Validity of combinations encoded at compile time.
template <class Model, class Payoff> concept ClosedForm     = /* traits */;
template <class Model>               concept Recombining    = /* traits */;
template <class Payoff>              concept LipschitzPayoff = /* traits: pathwise admissible */;
```

Every concrete type is checked in the tests with `static_assert(Pricer<...>)`, so that a concept error shows up in the right place and not deep inside a `std::visit`.

### 2.5 Why no inheritance, and where to keep the `std::variant`

- **Hot path:** templates constrained by concepts. `fd_greeks<Pricer P>` is written once, inlined, with no virtual call.
- **Comparison layer:** `std::variant` + `std::visit`, kept from v1 (closed set, value semantics, no allocation, exhaustiveness checked).
- **Limit of v1:** as soon as Heston and Merton come in, a variant of *methods* is no longer enough. The variant holds **pre-validated scenarios** `Scenario<Model, Payoff, Method>`, built by a factory that rejects invalid combinations at compile time.
- **Compile time:** explicit instantiations in `src/`, `extern template` in the headers.
- **Pitfall to anticipate (new in v2):** an ill-formed concept `static_assert` deep inside a template factory can produce a wall of unreadable errors. Every factory constraint must carry an explicit message (`static_assert(ClosedForm<Model,Payoff>, "no closed form for this combination")`), tested in isolation before being composed.

### 2.6 Forward automatic differentiation through templates

Models are templated on the scalar: `GBM<Real>`. Instantiated with `Dual<double>` (≈ 80 lines), the MC engine produces **pathwise Greeks automatically**, which gives an independent cross-check of the hand-written pathwise derivatives. AAD (adjoint mode) stays off the critical path — to be considered only after Phase 8, never before.

### 2.7 What we take from QuantLib and what we leave

- **Taken:** the `Instrument` / `PricingEngine` separation — exactly the "one instrument, several engines" requirement.
- **Left:** pervasive `shared_ptr`, `Handle<>`, deep virtual hierarchies in hot loops. Being able to explain *why* we do it differently in C++20 is stronger than either approach alone.

## 3. Mathematical foundations and reference values

### 3.1 Black-Scholes with continuous dividend

```
d1 = [ln(S/K) + (r − q + σ²/2)T] / (σ√T),   d2 = d1 − σ√T
C  = S e^{−qT} N(d1) − K e^{−rT} N(d2)
P  = K e^{−rT} N(−d2) − S e^{−qT} N(−d1)
```

**Canonical vector ✅** (S = K = 100, r = 5 %, q = 0, σ = 20 %, T = 1):

| Quantity | Value |
|---|---|
| d1, d2 | 0.35; 0.15 |
| Call | 10.450584 |
| Put | 5.573526 |
| Delta (call) | 0.636831 |
| Gamma | 0.018762 |
| Vega (per 1.00 of vol) | 37.524035 → **0.375 per vol point** |
| Theta (call, per year) | −6.414028 → **−0.01757 per calendar day** |
| Rho (per 1.00 of rate) | 53.232482 |

**Tested invariants** (beyond "price ≈ expected"):

- put-call parity to ~1e-14;
- bounds: max(0, S e^{−qT} − K e^{−rT}) ≤ C ≤ S e^{−qT};
- monotonicity: ∂C/∂K < 0, ∂C/∂σ > 0, ∂C/∂S > 0;
- convexity in strike (butterfly ≥ 0): no static arbitrage;
- tails: N(x) computed as `0.5 * std::erfc(-x / std::sqrt(2.0))`, never as `1 − N(−x)`.

**Implied volatility:** Jäckel, *Let's Be Rational* (2015) as the target; Brent on a bracketing interval as the fallback; **never Newton alone** (diverges in the deep wings where vega → 0). Gate: price → vol → price round trip on a grid covering moneyness 0.5–2 and T from 1 day to 5 years.

### 3.2 Binomial trees

```
Δt = T/n,  u = e^{σ√Δt},  d = 1/u,  p = (e^{(r−q)Δt} − d)/(u − d)
```

- **Validity:** p ∈ (0,1) ⇔ Δt < σ²/(r − q)². Assertion mandatory.
- **Memory:** in-place backward induction on a single vector, O(n) (v1: 400 MB → 0.08 MB at n = 10,000).
- **Non-monotone convergence:** the CRR error changes sign with every n (position of the strike between terminal nodes, Leisen-Reimer 1996). Sampling only even n produces an artificially clean slope of −1. The report plots **consecutive n**.
- **Remedies studied:** averaging (Vₙ + Vₙ₊₁)/2; **Leisen-Reimer** (Peizer-Pratt inversion, odd n, O(1/n²) convergence); **BBS** (Broadie-Detemple: BS at the second-to-last step) + Richardson extrapolation.
- **Free Greeks:** delta and gamma read off the nodes at steps 1 and 2; theta via a tree starting two steps before t = 0.
- **American invariants ✅ (n = 20,000):** American put 6.090333 > European put 5.573426 (early-exercise premium 0.516907); American call without dividend = European call exactly (Merton's theorem).

### 3.3 Monte Carlo under GBM

- European payoff: **direct draw of S_T** in log space, without time steps (exact, no discretization bias).
- Path-dependent payoff: time steps in log space (exact at the observation dates for GBM); the *discrete monitoring* bias of a barrier is a separate effect, documented and correctable (Broadie-Glasserman-Kou).
- O(N^{−1/2}) convergence checked by log-log slope **and** by **empirical coverage**: 1,000 independent pricings, ~95 % of the 95 % CIs must contain the BS price. Almost no student project runs this test.

## 4. Monte Carlo: sampling and variance reduction

### 4.1 Metric

**Efficiency = 1 / (Var × CPU time)** (Glasserman). Every table in the report gives variance, time and relative efficiency. v1 measured, at equal draws: antithetic 4×, S_T control 6.9×, antithetic + control **58×** (in path equivalents). Message to keep: **variance reduction beats parallelism** (58× from mathematics versus ~6× from 8 threads) — to be reconfirmed in CPU efficiency.

### 4.2 Techniques, with their failures

| Technique | Works when | Fails when (to be shown) |
|---|---|---|
| Antithetic | Payoff monotone in Z (call, put) | ATM straddle: payoff nearly even in Z, zero or even negative efficiency gain |
| S_T control, E = S₀e^{(r−q)T} | ITM calls, strong correlation | Deep OTM calls: correlation collapses |
| Geometric Asian control | Arithmetic Asian (closed form for the geometric, correlation > 0.99) | — the "spectacular" demonstration |
| BS control under Heston | Same Z, moderate gain | Degrades with vol-of-vol: an indirect measure of the model gap |
| Sobol QMC (Joe-Kuo) + Brownian bridge + Owen scrambling | Low effective dimension, smooth payoffs | Discontinuous payoffs; without randomization, no standard error |
| Importance sampling (mean shift) | Deep OTM digitals, VaR tails | Poor choice of shift: variance blows up |

**Details that matter:**

- The optimal control β* is estimated on an **independent pilot**; estimating it on the same paths introduces an O(1/N) bias, small but worth mentioning.
- In QMC, **no Box-Muller**: it destroys the low-discrepancy structure. Inverse CDF only.

### 4.3 Reproducible generator and parallelism

- **Philox 4×32-10**: substream indexed by (seed, block id), no shared state, no skip-ahead.
- **Decomposition into K fixed blocks**, independent of the thread count. Each block produces a Welford accumulator; the partials are reduced **in block order** (Chan merge). Result **bit-identical** with 1 or 64 threads.
- Phase 2 gate: same result to the bit with 1, 2, 8 threads, on GCC and Clang.
- **Explicit contingency (new in v2):** Philox + AS241 are new infrastructure, not known formulas copied from a textbook — this is the part of the plan most likely to slip. If Phase 2 runs past 1.5 weeks, fall back to `std::mt19937_64` + in-house inverse normal (keeps reproducibility *per compiler*, loses the *cross*-compiler guarantee) rather than letting the delay propagate along the whole critical path. Document the fallback as a known limitation in the report if used.

## 5. Greek estimation under noise (flagship section)

### 5.1 Protocol

Four estimators × two payoffs (**call**: continuous with a kink; **digital**: discontinuous) × three regimes (ATM, deep OTM, short T). For each cell: bias, variance, RMSE, cost, efficiency, as functions of h and N.

### 5.2 Theoretical results to confirm empirically

| Estimator | Call (Lipschitz) | Digital (discontinuous) |
|---|---|---|
| **Central FD, independent seeds** | Bias O(h²), Var O(1/(N h²)) → h* ∝ N^{−1/6}, RMSE ∝ N^{−1/3}. Blows up as h → 0. | Same, worse |
| **Central FD + CRN** | Var O(1/N), independent of h → RMSE ∝ N^{−1/2} | Var O(1/(N h)) → h* ∝ N^{−1/5}, RMSE ∝ N^{−2/5}. **CRN do not fix everything.** |
| **Pathwise** | Unbiased, low variance, a single pass | **Zero almost surely: converges confidently to a wrong answer** |
| **Likelihood ratio** | Unbiased, higher variance | Unbiased; variance ∝ 1/T as T → 0 |

**Illustration measured in v1 (200,000 paths, true delta 0.636831):** with h = 0.01, FD without CRN gives 3.387 (error +275 %); with CRN, 0.6345, stable over four orders of magnitude of h.

**FD gamma of a call, even with CRN:** the payoff kink means the second difference only contributes within a band of width h around the strike, with an amplitude of 1/h; the variance behaves as O(1/(N h)), exactly like a digital delta.

### 5.3 Formulas (GBM, Z ~ N(0,1) driving S_T)

```
Pathwise   Δ = e^{−rT} E[ 1{S_T > K} · S_T / S₀ ]
           ν = e^{−rT} E[ 1{S_T > K} · S_T (√T·Z − σT) ]
LR         Δ = e^{−rT} E[ payoff · Z / (S₀ σ √T) ]
           Γ = e^{−rT} E[ payoff · (Z² − 1 − Zσ√T) / (S₀² σ² T) ]
Mixed      Γ = LR applied to the pathwise delta estimator (lower variance than pure LR)
```

v1: pathwise delta 0.634511 and LR gamma 0.018554 (true 0.018762), to be reproduced with standard errors.

### 5.4 Floating-point rounding on deterministic pricers

On analytic BS, plot the FD error against h: a **V-curve** (O(h²) truncation on the right, O(ε/h) rounding for delta and O(ε/h²) for gamma on the left). h* ≈ S·ε^{1/3} for delta, ≈ S·ε^{1/4} for gamma. **Relative** bump, never absolute.

### 5.5 Deliverable

A **recommendation matrix** payoff × regime × estimator, and an operational decision rule for a model-validation team.

## 6. Risk measures on non-linear positions

### 6.1 The central demonstration

Position: **short ATM straddle, delta-hedged**. Delta ≈ 0, so **delta-normal VaR ≈ 0**, while the real loss ½·Γ·ΔS² is large and asymmetric.

**Preview ✅** (30-day straddle, σ = 20 %, r = 5 %, 1-day horizon, 10⁶ scenarios, per straddle): delta-normal VaR = **0**; 99 % full-revaluation VaR ≈ **0.64**; 97.5 % ES ≈ **0.66**. To be regenerated and extended in Phase 6.

### 6.2 Progression of methods

1. **Delta-normal**: blind to gamma by construction.
2. **Delta-gamma normal** (moments of a quadratic form projected onto a normal): partial improvement; the true law is a skewed non-central χ²-type distribution, and the tail is still underestimated. **Cornish-Fisher** improves without solving it.
3. **Full revaluation**, Monte Carlo and historical: captures the optionality.
4. **Joint vol shocks**: the short straddle is also short vega; a spot-only VaR misses this risk.

### 6.3 Conventions (the source of most bugs)

- VaR reported as a **positive loss**; 99 % = the 1st percentile of P&L.
- Quantile estimator: index ⌈αN⌉ on the sorted losses; `std::nth_element` (O(N)).
- √10 scaling: assumes i.i.d. returns, **wrong** under volatility clustering; to be demonstrated, not used silently.
- **Bootstrap CI on every VaR**: the variance of the quantile estimator ∝ α(1−α)/(N f(q)²), huge in the tail (v1: 5.6 % error at N = 1,000).

### 6.4 Expected Shortfall: not optional

- **Non-subadditivity of VaR ✅**: two independent bonds, 4 % default, loss 100: VaR95(A) = VaR95(B) = 0 but VaR95(A+B) = 100. Diversification *increases* VaR (Artzner et al., 1999).
- **FRTB** (BCBS d457, 2019): ES 97.5 % replaces VaR 99 %. Under normality, ES 97.5 % = 2.3378 ≈ VaR 99 % = 2.3263.

| α | VaR (N(0,1)) ✅ | ES ✅ |
|---|---|---|
| 95 % | 1.6449 | 2.0627 |
| 97.5 % | 1.9600 | 2.3378 |
| 99 % | 2.3263 | 2.6652 |

### 6.5 Backtesting

- **Kupiec POF** (unconditional coverage) and **Christoffersen** (independence of exceedances).
- **Basel traffic lights** over 250 days: green 0–4 exceedances, yellow 5–9, red ≥ 10.
- Expected result: on real data, exceedances cluster in crises; this is the signature of fat tails and the clustering that GBM ignores.

## 7. Model risk beyond GBM

**Scope (new in v2): this phase is explicitly the first extension to cut if time runs short (§12.1).** The core of the project (§1–§6) is already differentiating and complete without it. Do not start Phase 7 until Phase 6 is validated and written up.

### 7.1 Models

- **Heston**: simulation with **Andersen's QE scheme (2008)**; full-truncation Euler as a counterexample; semi-analytic price via the characteristic function in the **Albrecher et al. (2007)** formulation (avoids the branch cut of the complex logarithm). Feller condition 2κθ > ξ²: study both regimes.
- **Merton (log-normal jumps)**: closed-form price as a weighted series of BS prices; exact simulation (Poisson + normal).

### 7.2 Three experiments

1. **Same ATM price, diverging exotic prices.** Calibrate BS, Heston and Merton to the same ATM price (or the same small smile), then price an OTM call, a digital and an up-and-out barrier. The gap between models *is* the measure of model risk. Barriers are notoriously sensitive to vol-of-vol even when vanillas coincide.
2. **Hedging in the wrong world.** Delta-hedge with the BS delta while the simulated world is Heston or Merton; plot the distribution of hedging P&L as a function of rebalancing frequency. Compare with P&L ≈ ½ Γ S² (σ²_realized − σ²_implied) dt. Under Merton, an unhedgeable residual P&L remains whatever the frequency.
3. **Error decomposition under Heston.** Discretization bias (↓ with dt) against statistical error (↓ with N); show that QE removes most of the former. This is where the `Estimate::discretization` field earns its place.

## 8. Performance engineering

A deliberately secondary section in the report; useful, but not the thesis.

- **Threads:** `std::jthread` + block pool (or OpenMP). Avoid `std::async` (implementation-defined launch policy) and `std::execution::par` (uneven support: libstdc++ depends on TBB, libc++ incomplete).
- **False sharing:** thread-local accumulators, written once; `alignas(std::hardware_destructive_interference_size)` when a shared array is unavoidable. v1 measured a ~9.7× slowdown; to be re-measured and shown as a profiling study.
- **SoA and batches of normals** (1,024 to 4,096) to enable vectorization; `exp` dominates the inner loop.
- **Trees:** precomputed powers of u instead of `std::pow` in the inner loop.
- **Indicative targets (v1, to be reconfirmed):** BS < 100 ns; tree n = 1,000 < 5 ms; MC 1M paths single-threaded < 20 ms; parallel efficiency at 8 threads > 70 %.
- **Measurement rigor:** Google Benchmark, median and spread, CPU model, compiler and flags recorded. Explaining the gap to linear scaling (hyperthreading, frequency drop under load, memory bandwidth) is worth more than claiming a linear speedup.

## 10. Technical pitfalls (risk register)

| Pitfall | Symptom | Countermeasure |
|---|---|---|
| Implementation-defined `std::` distributions | Numbers differ by compiler | Philox + in-house inverse normal |
| Non-deterministic parallel reduction | Result depends on the thread count | Fixed blocks, ordered reduction |
| `-ffast-math`, FMA contraction | Undetected NaN, drift between compilers | Forbidden in reference builds; relative tolerances in tests |
| Catastrophic cancellation in FD | Noisy or wrong gamma for small h | Relative bump, documented h*, V-curve in the report |
| Tail of N(x) via 1 − N(−x) | Zero precision in the tail | `erfc` |
| T → 0, σ → 0 | Division by zero, NaN | Explicit branches to the intrinsic value, dedicated tests |
| p outside (0,1) in CRR | Plausible but wrong prices, arbitrage | Assertion |
| Negative variance under Heston-Euler | NaN or massive bias | Full truncation or QE |
| Branch cut of the complex logarithm (Heston CF) | Wrong semi-analytic prices for long T | Albrecher et al. formulation |
| Box-Muller in QMC | Loss of low discrepancy | Inverse CDF |
| Conventions (252/365, vega per 1 % or 1.00, theta per day or year) | Errors by a factor of 100 or 365 | `docs/conventions.md` from Phase 1, strong typedefs |
| MC tests with fixed tolerance | Flaky or too lax tests | \|MC − ref\| < 4·SE, fixed seed |
| Unreadable concept errors | Diagnostic deep inside a `std::visit` | Per-type `static_assert` in the tests |
| Compile-time explosion | Slow builds | Explicit instantiations, `extern template` |
| Scope creep | Project never finished | **No feature without a planned figure in the report** |

## 11. Testing and reproducibility strategy

**Three levels of tests:**

1. **Unit and reference values**: canonical vectors (§3.1), published values for American options and Heston.
2. **Invariants**: parity, bounds, monotonicity, convexity, American ≥ European, American call without dividend = European.
3. **Statistical**: \|MC − ref\| < 4·SE; convergence slopes within an interval; CI coverage; moments and Kolmogorov-Smirnov of the generator.

**Experiment harness:** each executable in `experiments/` writes `data/results/<id>.csv` and `<id>.meta.json` (git SHA, compiler, flags, seed, N, date). `tools/make_figures.py` produces `docs/figures/`. `make report` regenerates everything.

**The report as a test:** a weekly CI job reruns the experiments and fails if a number quoted in the report drifts beyond its statistical tolerance.

**CI:** GCC, Clang, MSVC; `-Wall -Wextra -Werror`; ASan/UBSan job; clang-format and clang-tidy.

In order, the first thing to sacrifice is always the most recent addition to the scope, never the validated core:

## 13. Outline of the final report

`docs/model_risk_report.md`, written as an institutional-grade model-validation paper.

**Executive summary** — three or four quantified findings, in one paragraph, with their confidence intervals.

1. **Introduction and risk taxonomy**
   1.1 Numerical-method risk, risk-measure risk, model risk
   1.2 Scope: what the report demonstrates and what it does not claim
2. **Setup, conventions and reproducibility**
   2.1 Dynamics, reference parameters, unit conventions
   2.2 Protocol: generator, seeds, efficiency metric, regeneration
3. **Ground truth: analytic Black-Scholes**
   3.1 Validation, invariants, implied volatility
   3.2 Floating-point rounding and the finite-difference V-curve
4. **Trees: convergence and pathologies**
   4.1 Even/odd oscillations of CRR and their origin
   4.2 Leisen-Reimer, BBS, Richardson: measured orders
   4.3 Early exercise
5. **Monte Carlo: convergence and variance reduction**
   5.1 N^{−1/2} rate and interval coverage
   5.2 Efficiency table, failures included
   5.3 Randomized quasi-Monte Carlo
6. **Greek estimation under noise** *(flagship section)*
   6.1 Why naive FD fails: bias/variance analysis
   6.2 CRN: what they fix and what they do not
   6.3 Pathwise, LR, mixed estimator; the silent failure on the digital
   6.4 Recommendation matrix
7. **Risk measures on non-linear positions**
   7.1 The blindness of delta-normal VaR on a short straddle
   7.2 Delta-gamma and Cornish-Fisher
   7.3 Full revaluation, historical, Expected Shortfall, subadditivity
   7.4 Backtesting and historical stress scenarios
8. **Model risk beyond GBM** *(if Phase 7 was done — otherwise a short section explaining the uncovered scope, see §12.1)*
   8.1 Common calibration, diverging exotics
   8.2 Hedging P&L in a misspecified world
   8.3 Discretization bias against statistical error
9. **Engineering and performance notes** *(short)*
10. **Limitations and future work**
11. **Conclusion: operational recommendations** for a desk or a model-validation team

**Appendices:** A. derivations of the pathwise and LR estimators; B. parameter tables; C. reference values and sources; D. reproduction procedure.

**Editorial rules:**

- Every figure has a self-contained caption: *what it shows*, then *why it matters*.
- Every number points to the CSV that produced it.
- Every stochastic estimate is given with its standard error or CI.
- Every negative claim ("X fails") comes with its mechanism and its remedy.
